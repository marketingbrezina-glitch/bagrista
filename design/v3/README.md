# Jsem Bagrista — Věstník bagrovací komunity

Statický web (HTML + React/Babel přes CDN, bez build kroku).

Otevři `index.html` v prohlížeči nebo nasaď obsah složky na GitHub Pages / Netlify / Vercel jako statický web.

## Soubory
- `index.html` — vstupní bod (router, načtení skriptů)
- `styles.css` — design system (Playfair Display + Source Serif 4)
- `data.js` — obsah (stupně, sekty, slovník, modlitby, kvíz, mučedníci, dějiny)
- `components.jsx` — hlavička, patička, sdílené prvky
- `pages-a.jsx`, `pages-b.jsx`, `pages-c.jsx` — stránky
